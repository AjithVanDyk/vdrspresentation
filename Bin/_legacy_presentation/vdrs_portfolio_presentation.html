Project 1: RAG Chatbot System

My First AI Project - Learning Advanced Technologies

Problem I Observed

Technicians spend 2+ hours searching through equipment manuals - similar to how we wasted time at Hero MotoCorp searching for maintenance procedures.

What I Built

AI-powered search system that understands natural language questions and finds answers instantly from thousands of documents. This was my introduction to AI/ML - completely new territory coming from manufacturing!

(Screenshot showing chat interface with query and response)

Technologies I Learned & Applied

  • OpenAI GPT-4: My first experience with Large Language Models - learned how to prompt AI effectively
  • ChromaDB Vector Database: Completely new concept - storing "meaning" instead of just text
  • Python for AI: Previously used Python for data analysis; now learned AI libraries like LangChain
  • Streamlit: Discovered how to build web apps quickly with Python (no HTML/CSS needed)

Key Learning & Infrastructure Reality

Important Insight from This Project

While technically successful (99.6% faster searches, 95% accuracy), I learned that Van Dyk's needs don't align with self-hosted AI infrastructure. As a service company, not IT company, better solutions exist:

  • Intercom Fin AI: Cloud-based, no servers needed
  • CRM AI Integration: Salesforce Einstein, HubSpot AI
  • Microsoft 365 Copilot: Leverages existing infrastructure

This POC validates the business case ($40K potential value) for evaluating commercial enterprise solutions.

Project 5: DykScribe

Capturing Field Knowledge with AI

Problem - Knowledge Loss

At Hero MotoCorp, I experienced this: When experienced technicians left, their knowledge left with them. Same problem here at Van Dyk with 50+ field technicians.

My Solution - Voice to Knowledge

System where technicians just speak for 2-5 minutes about how they fixed something. AI transcribes, organizes, and makes it searchable. Simple for them, powerful for organization.

🎤 IMAGE: DykScribe Recording Interface
(Audio recording screen with equipment selection dropdowns)

How It Works - Step by Step

🎤 → 🔊 → 🤖 → 💾 → 🔍
1
Record Audio: Technician speaks about repair (browser recording or file upload)
2
Whisper Transcribes: AI converts speech to text (98% accuracy, even with technical terms)
3
GPT-4 Organizes: Structures into Q&A pairs, removes filler words
4
Database Stores: Saved with equipment metadata - searchable by anyone

(Before/after showing audio transcript → structured Q&A)

Personal Reflection

Why This Matters to Me: At Hero MotoCorp, I digitized maintenance systems and saw how capturing knowledge improved efficiency. DykScribe takes it further - using AI to make knowledge capture effortless. 500+ Q&A pairs in 3 months proves technicians will use it!

Project 7: VDRS360

Equipment Lifecycle Management Platform

Familiar Problem from Manufacturing

5,000+ equipment records across 200+ customers lacked centralized management - reminded me of tracking 200+ machines at Hero MotoCorp Haridwar plant.

Applying Manufacturing Experience

Built equipment management system inspired by my TPM experience - comprehensive tracking, maintenance history, dynamic specifications based on equipment type.

📊 IMAGE: Equipment Data Grid
(Excel-like interface)
🕸️ IMAGE: Network Visualization
(Customer→Project→Equipment graph)
🔍 IMAGE: Advanced Search
(Multi-field filter interface)

Smart Feature: Dynamic Specifications

Problem I Solved

Database has 50 generic "Specification" columns. But BALER needs Weight/Motor Power, CONVEYOR needs Belt Width/Speed - different fields!

My Solution: System automatically changes column labels based on equipment type selected. Users see only relevant fields - no confusion!

Like at Hero MotoCorp: We tracked different parameters for Honing machines vs Laser Marking machines. Same principle applied to software!

Technologies Applied

  • Streamlit: Web-based Excel-like interface
  • PyVis: Interactive network graphs (shows equipment relationships visually)
  • SQLAlchemy: Database ORM with connection pooling
  • Hash-based Change Detection: Only saves modified rows (prevents errors, improves speed)

Business Impact

Metric Result

Data Accuracy 85% → 98%
